# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in enumplus, please report it
responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please email **mathias.paulenko@outlook.com** with:

1. A description of the vulnerability.
2. Steps to reproduce the issue.
3. The potential impact of the vulnerability.
4. Any suggested fixes (optional).

You will receive a response within 48 hours. If the vulnerability is confirmed,
a fix will be prepared and a security advisory will be published.
