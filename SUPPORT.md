# Support

## Getting Help

- **Documentation**: Start with the [README](README.md) for usage examples and API reference.
- **Issues**: Search [existing issues](https://github.com/MathiasPaulenko/enumpy/issues) to see if your question has already been answered.
- **Discussions**: Use [GitHub Discussions](https://github.com/MathiasPaulenko/enumpy/discussions) for questions, ideas, and general discussion.

## Reporting a Bug

Open a [bug report issue](https://github.com/MathiasPaulenko/enumpy/issues/new?template=bug_report.md).
Include:

- Python version
- enumplus version (`pip show enumplus`)
- Minimal reproducible example
- Expected vs actual behavior

## Requesting a Feature

Open a [feature request issue](https://github.com/MathiasPaulenko/enumpy/issues/new?template=feature_request.md).

## Security Issues

See [SECURITY.md](SECURITY.md) for reporting security vulnerabilities. **Do not
open a public issue for security-related problems.**
